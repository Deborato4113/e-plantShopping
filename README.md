# Paradise Nursery Shopping Application

Paradise Nursery is an online shopping platform where plant enthusiasts can browse a curated collection of houseplants, explore categorized selections, and manage items within an interactive shopping cart.

## Features
- Landing page with company background and "Get Started" navigation.
- 18+ unique houseplants grouped across 3 categories.
- Real-time cart badge counter.
- Redux Toolkit state management for adding, updating, and removing items.
- Dynamic cart pricing, subtotal, and total calculation.
